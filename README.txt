1. Создайте аккаунт на github.com и новый репозиторий (New repository).
2. Загрузите в него всё содержимое этого архива (Add file > Upload files).
   Если папка .github не загрузилась: Add file > Create new file, имя
   .github/workflows/build.yml , вставьте текст из файла build.yml.txt.
3. Откройте вкладку Actions, дождитесь зелёной галочки (5-10 минут).
4. Откройте завершённый запуск, внизу в Artifacts скачайте road-playlist-apk.
5. Распакуйте zip, перенесите app-debug.apk на телефон и установите
   (разрешите установку из неизвестных источников).
